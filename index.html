An audit of one AI-assisted workflow: using ChatGPT to generate the HTML code for a conceptual educational prototype of a kids’ fintech landing page.

1. Classify

Risk tier: minimal risk. ChatGPT was used as a drafting assistant to generate HTML code for a conceptual educational prototype. No personal, customer, employee or confidential data was processed, and the output does not make decisions about anyone’s rights, money, health, jobs or access to services.

2. Check

Fundamental rights impact assessment: not needed. This use is not high-risk, so no assessment is required.

3. Apply: five-point hygiene check

CheckResultEvidence
BiasPASSThe workflow uses public strategic concepts and structural content, with no individual-level profiling or decision-making.
PrivacyPASSNo personal, customer, employee or confidential data was entered into the AI system.
ConsentPASSNo third-party personal data was processed, and the assignment context permits AI assistance as described.
AttributionPASSThe module instructor and peers are aware that AI was used to assist in creating the assignment.
TransparencyPASSThe AI-assisted nature of the work is disclosed to the relevant academic audience.

4. Document: remediation, in order

  1. Keep a brief record of the AI assistance used, including that ChatGPT generated or assisted with the HTML code, so the AI contribution can be explained if requested.
  2. Verify the generated code yourself before submission: confirm the file is complete (an earlier version was cut off before its closing tags) and replace any placeholder text such as the product name.
  3. Check the final work against your module’s academic integrity and AI-use requirements.
  4. Repeat this audit, with a new date, whenever the workflow changes.
